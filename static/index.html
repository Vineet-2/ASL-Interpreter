How it works

Six agents. One voice.

Every sign you make is processed by a coordinated pipeline of specialized AI agents before becoming natural-sounding speech.

👁️

Vision Agent

Tracks your hands in real time using MediaPipe, extracting 63 precise landmark coordinates per frame.

🖐️

Sign Recognition

A trained BiGRU model (or geometric fallback) maps landmark sequences to ASL glosses with confidence scoring.

🧠

Context Agent

Resolves pronoun ambiguity, homonyms, and role-based signing using conversation history and grammar rules.

💬

Language Agent

Translates ASL glosses to fluent English via Groq/Gemini LLMs, with graceful local fallback.

🔊

Speech Agent

Synthesizes natural-sounding audio from translations using server TTS or the browser's Speech API.

🗂️

Memory Agent

Keeps a rolling conversation transcript so context carries across multiple signing turns.
